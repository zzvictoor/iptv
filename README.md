# IPTV BR teste

Repositório de teste com playlists no formato M3U.

## Ficheiros

- `oloco.m3u` — playlist organizada por grupos/categorias.
- `teste.m3u` — playlist usada para testes.

## Utilização

Os ficheiros são listas M3U e devem ser abertos apenas em leitores compatíveis com esse formato. Este repositório não inclui aplicação, processo de build ou dependências próprias.

Ao editar uma playlist, mantém o cabeçalho e a estrutura das entradas existentes para evitar problemas de parsing em leitores M3U.

> Os endereços presentes nas playlists podem deixar de estar disponíveis com o tempo. A existência de uma entrada no repositório não garante disponibilidade do respetivo recurso.
